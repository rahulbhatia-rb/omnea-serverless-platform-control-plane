# Golden Path

A product engineer should be able to:

1. choose a supported workload template;
2. declare regional and data-residency requirements;
3. consume reusable Pulumi TypeScript components;
4. get GitHub Actions test, security, and Pulumi preview feedback on the pull request;
5. deploy progressively;
6. receive Datadog ownership, dashboards, SLOs, and deployment markers by default;
7. roll back automatically when production validation fails.

The platform should generate common controls instead of requiring every team to rediscover them.

Exceptions should remain possible for legitimate cases, but require an owner, expiry, and documented rationale so temporary workarounds do not become permanent platform architecture.
